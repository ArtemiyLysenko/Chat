Milestone 4 notes

  • Reverse-direction requests auto-accept the existing pending request.
  • Open dialog reuses one stable direct-dialog identity per ordered user pair.
  • Unread badges come from HTTP-backed read markers and clear when the chat view advances the marker.
  • Blocking or removing a friend preserves existing dialog history, but new direct messaging stays ineligible.
  • Direct unread badges now refresh live over the authenticated `/ws` channel without reopening the contacts workspace.

Accepted friends

These relationships are the only pairs currently eligible to open or reopen a direct-dialog timeline when no block exists.

Inbound pending

Accept, reject, or block requests addressed to the current user.

Outbound pending

These requests are still waiting for the other user to respond. You can still block the target.

Blocked users

These users cannot exchange new friend requests or new direct messages while the block is active.
