Milestone 1

Classic chat entry, backed by durable browser sessions.

This slice delivers registration, persistent login, password lifecycle flows, active-session control, and the first authenticated shell that later milestones will fill with rooms, contacts, messaging, and Jabber federation tooling.

What ships in this milestone

  • Registration and cookie-based login with PostgreSQL-backed sessions.
  • Password change, reset request, reset consume, and account deletion entry.
  • Selective session revocation with a dedicated session-management screen.
  • Static browser pages served directly by the Spring Boot app.
