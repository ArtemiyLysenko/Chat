Milestone 3.3 notes

  • Reverse-direction requests auto-accept the existing pending request.
  • Open dialog placeholder creates or reuses one stable direct-dialog identity per ordered user pair.
  • Blocking or removing a friend preserves an existing direct-dialog identity, but new messaging stays ineligible.

Accepted friends

These relationships are the only pairs currently eligible to ensure or reopen a stable direct-dialog placeholder when no block exists.

Inbound pending

Accept, reject, or block requests addressed to the current user.

Outbound pending

These requests are still waiting for the other user to respond. You can still block the target.

Blocked users

These users cannot exchange new friend requests or new direct messages while the block is active.
